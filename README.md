# Flask Web Server - Praktikum Pertemuan 1

**Aplikasi Web Server Sederhana**
&nbsp;&nbsp;&nbsp;&nbsp;Aplikasi web server sederhana berbasis Python Flask yang menampilkan informasi perangkat (hostname, sistem operasi, dan arsitektur).

**Cara Menjalankan**
&nbsp;&nbsp;&nbsp;&nbsp;1. Install dependensi: `pip install -r requirements.txt`  
&nbsp;&nbsp;&nbsp;&nbsp;2. Set variabel lingkungan pengembang:  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`export APP_AUTHOR="Nama Lengkap - NIM"`  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`export APP_ENV="development"`  
&nbsp;&nbsp;&nbsp;&nbsp;3. Jalankan server: `python server.py`  

**Akses Aplikasi**
&nbsp;&nbsp;&nbsp;&nbsp;Buka browser lalu kunjungi: http://localhost:5000
